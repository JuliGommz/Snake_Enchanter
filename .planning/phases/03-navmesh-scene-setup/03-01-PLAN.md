  <name>Task 1: Fix FBX Mesh Compression and Create NavMeshSurface</name>
  <files>Assets/_Project/Scenes/GameLevel.unity</files>
  <action>
    Unity Editor task — no code changes. Two parts:
    Part A: Fix FBX Mesh Compression on cave/environment assets (prevents silent bake failure).

  <verify>NavMeshSurface GameObject exists in GameLevel Hierarchy with NavMeshSurface component showing Agent Height: 0.5 in Inspector.</verify>
  <done>NavMeshSurface component configured in GameLevel scene with Collect Objects: All Game Objects, Agent Height: 0.5, Agent Radius: 0.3. Scene saved (Ctrl+S).</done>
  <what-built>Nothing automated — this is a Unity Editor setup task requiring manual Inspector interaction.</what-built>
  <how-to-verify>
    Follow these steps in the Unity Editor:

    STEP 1 — Fix FBX Mesh Compression (prevents silent bake failure)
    ----------------------------------------------------------------
    There is a known Unity bug where FBX assets with Mesh Compression set to
    Low or Medium are silently skipped during NavMesh baking. Fix this first.

    1. Open the Project window in Unity
    2. Navigate to cave/environment assets (search "caves" or "dwarven" in Project window)
       These are likely in: Assets/External_Assets/ or similar
    3. Select each cave FBX asset (floor/ground mesh FBXs)
    4. In the Inspector, click the "Model" tab
    5. Find "Mesh Compression" dropdown
    6. If it shows Low or Medium — change it to "Off"
    7. Click "Apply"
    8. Repeat for all environment FBX assets used as cave floors/walls

    If all assets already show "Off" or "High" — no change needed, continue.

    STEP 2 — Open GameLevel Scene
    --------------------------------
    1. In Project window: Assets/_Project/Scenes/
    2. Double-click GameLevel.unity to open it
    3. Confirm the scene is loaded in the Scene view

    STEP 3 — Create NavMeshSurface GameObject
    ------------------------------------------
    1. In the Hierarchy window, right-click on an empty area
    2. Select: Create Empty
    3. Rename the new GameObject to exactly: NavMeshSurface
    4. In the Inspector, verify Transform shows Position (0, 0, 0) — leave at world origin
    5. With NavMeshSurface selected in Hierarchy, click "Add Component" in Inspector
    6. Type "NavMesh" in the search box
    7. Select: "NavMesh Surface" (from com.unity.ai.navigation package)
       IMPORTANT: Do NOT select "NavMesh Obstacle" or "NavMesh Agent" — only "NavMesh Surface"

    STEP 4 — Configure NavMeshSurface settings
    -------------------------------------------
    With the NavMeshSurface component visible in the Inspector, set these values:

    - Agent Type: Humanoid (default — leave as is)
    - Collect Objects: All Game Objects
    - Include Layers: Everything (default)
    - Use Geometry: Render Meshes
    - Default Area: Walkable
    - Override Voxel Size: UNCHECKED (leave default)
    - Override Tile Size: UNCHECKED (leave default)
    - Minimum Region Area: 2 (default)
    - Build Height Mesh: UNCHECKED

    STEP 5 — Set Agent Height to 0.5
    --------------------------------
    CRITICAL: Default Agent Height is 2.0, which blocks cave ceiling clearance.
    Snake height is ~0.5, so use 0.5.

    Method A — via Agent Type dropdown in NavMeshSurface:
    - Click the small dropdown next to "Agent Type: Humanoid"
    - Look for "Open Agent Settings" link
    - This opens Window > AI > Navigation > Agents tab
    - Select Humanoid agent, set Height: 0.5, Radius: 0.3
    - Press Enter or click elsewhere to confirm

    Method B — via Navigation window:
    - Open: Window > AI > Navigation
    - Click "Agents" tab
    - Select "Humanoid"
    - Set Height: 0.5
    - Set Radius: 0.3
    - Press Enter or click elsewhere to confirm changes

    STEP 6 — Save the scene
    -------------------------
    Press Ctrl+S to save GameLevel.unity before baking.
  </how-to-verify>

  <files>Assets/_Project/Scenes/GameLevel.unity</files>
  <action>

  <verify>Blue overlay visible on cave floor surfaces in Scene view (Navigation window must be open). NavMesh.asset exists at Assets/_Project/Scenes/GameLevel/NavMesh.asset. No errors in Console window.</verify>
  <done>NavMesh baked successfully. Blue overlay covers snake patrol floor areas. No ceiling surfaces baked as walkable. No console errors. Snakes still patrol normally in Play mode. Scene saved.</done>
  <what-built>Nothing automated — this is a Unity Editor bake operation.</what-built>
  <how-to-verify>
    Follow these steps in the Unity Editor:

    STEP 1 — Open Navigation window (required to see bake overlay)
    ---------------------------------------------------------------
    1. Menu bar: Window > AI > Navigation
    2. Dock the Navigation window somewhere visible (e.g., next to Inspector)
    3. Keep this window OPEN during and after baking — the blue overlay only
       appears when the Navigation window is open

    STEP 2 — Bake the NavMesh
    --------------------------
    1. Select the NavMeshSurface GameObject in the Hierarchy
    2. In the Inspector, find the NavMeshSurface component
    3. Click the "Bake" button at the bottom of the component
       IMPORTANT: Use THIS Bake button (on the component), not any button in the
       Navigation window — the Navigation window Bake is the legacy system.
    4. Wait for the bake to complete (progress bar at the bottom of Unity)
    5. Check the Console window for any errors or warnings

    STEP 3 — Verify the bake result in Scene view
    -----------------------------------------------
    You should see a BLUE OVERLAY on floor surfaces in the Scene view.
    - Expected: Main cave floor area(s) are blue
    - Expected: Walls and ceilings are NOT blue (or only tiny unavoidable patches)

    If NO blue overlay appears:
    - Confirm Navigation window is open (Window > AI > Navigation)
    - In Scene view, click the "Gizmos" dropdown and verify NavMesh overlay is enabled
    - Try: Select NavMeshSurface > click "Clear" > click "Bake" again
    - If still nothing: The FBX compression fix in Task 1 may not have been applied
      to the correct assets. Re-examine all cave floor FBX assets.

    If blue overlay covers CEILING areas:
    - Select the ceiling mesh GameObject(s) in the Hierarchy
    - Click "Add Component" > search "NavMesh Modifier" > add it
    - In NavMesh Modifier: check "Override Area" > set Area to "Not Walkable"
    - Select NavMeshSurface > click "Bake" again

    If only tiny disconnected patches appear (not connected floor coverage):
    - FBX compression was not fixed on all floor meshes
    - Check all environment FBX assets for Mesh Compression != Off
    - Fix and rebake

    STEP 4 — Test snakes in Play mode
    ----------------------------------
    1. Press Play button
    2. Watch snakes — they should still patrol their normal routes
    3. No new console errors should appear
    4. No behavioral changes should be visible (old movement system still active)
    5. Exit Play mode

    STEP 5 — Save the scene
    ------------------------
    Press Ctrl+S.
    Unity will have created: Assets/_Project/Scenes/GameLevel/NavMesh.asset
    Confirm this file exists in the Project window.
  </how-to-verify>
  <resume-signal>Type "baked" when NavMesh is visible as blue overlay and snakes still patrol normally, or describe the issue if bake failed or overlay is missing.</resume-signal>
