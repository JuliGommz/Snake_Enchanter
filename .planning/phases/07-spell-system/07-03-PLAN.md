  <action>
Create `Assets/_Project/Scripts/Player/ShieldComponent.cs` in namespace `SnakeEnchanter.Player`.

This MonoBehaviour goes on the Player GameObject (same object as HealthSystem). It manages the full shield state lifecycle.

**SerializeFields:**
- `float _shieldDuration = 8f` — how long shield lasts before expiring (user decision: 8 seconds)
- `UnityEngine.UI.Image _borderGlowImage` — reference to a full-screen UI Image with a transparent-center border sprite for screen edge glow
- `Color _shieldActiveColor = new Color(0.3f, 0.6f, 1f, 0.5f)` — blue/gold edge glow color
- `Color _shieldAbsorbFlashColor = Color.white` — flash color on absorb

**Private fields:**
- `bool _isShieldActive = false`
- `Coroutine _shieldTimerCoroutine = null`

**Properties:**
- `public bool IsShieldActive => _isShieldActive;`

**Public methods:**

`ActivateShield()`:
1. Guard: `if (_isShieldActive) return;` — cannot recast while active (user decision)
2. `_isShieldActive = true;`
3. Fire `GameEvents.ShieldActivated();`
4. Show screen glow: set `_borderGlowImage` color to `_shieldActiveColor`, `gameObject.SetActive(true)` on the image's gameObject
5. Start shield timer: `_shieldTimerCoroutine = StartCoroutine(ShieldTimerCoroutine());`

`TryAbsorbAttack()` — returns `bool`:
1. If `!_isShieldActive` return `false` (no shield, damage passes through)
2. Deactivate shield: call `DeactivateShield(absorbed: true)`
3. Fire `GameEvents.ShieldAbsorbedAttack();`
4. Start coroutine `AbsorbFlashCoroutine()` — quick white flash then hide
5. Return `true` (attack absorbed)

**Private methods:**

`ShieldTimerCoroutine()`:
- `yield return new WaitForSeconds(_shieldDuration);` — NOTE: WaitForSeconds is correct here (shield pauses with game)
- If `_isShieldActive`: call `DeactivateShield(absorbed: false)` — expired naturally

`DeactivateShield(bool absorbed)`:
1. `_isShieldActive = false;`
2. If `_shieldTimerCoroutine != null`: `StopCoroutine(_shieldTimerCoroutine); _shieldTimerCoroutine = null;`
3. Fire `GameEvents.ShieldDeactivated(absorbed);`
4. If NOT absorbed: hide glow image `_borderGlowImage.gameObject.SetActive(false)` — clean expire

`AbsorbFlashCoroutine()`:
1. Set `_borderGlowImage.color = _shieldAbsorbFlashColor;` (white flash)
2. `yield return new WaitForSeconds(0.15f);`
3. Hide glow: `_borderGlowImage.gameObject.SetActive(false);`

**Awake():**
- If `_borderGlowImage != null`: `_borderGlowImage.gameObject.SetActive(false);` — hidden by default

Add standard project header comment (AI-ASSISTED, version v1.0). Include a comment block describing the border glow sprite requirement: "Requires a UI Image with a border/vignette sprite (transparent center, colored edges) on a Screen Space - Overlay Canvas."

Do NOT subscribe to any GameEvents — ShieldComponent is activated directly by TuneController (in plan 07-04). It is a passive component that provides `ActivateShield()` and `TryAbsorbAttack()` as public API.
