Add spell casting rules to TuneController v3.0 (from plan 07-02). These are additions to the existing refactored code.

**New SerializeFields:**
- `float _spellCastRange = 8f` — range for Move/Daze casting (snake must be within this)
- `float[] _cooldownDurations = { 3f, 5f, 8f }` — cooldown per tune (Move, Daze, Shield)
- `int[] _spellCharges = { 5, 5, 3 }` — charges for Advanced mode (placeholder values per user decision — Phase 13 balancing)
- `LayerMask _snakeLayerMask` — for OverlapSphere (optional, can use default)

**New private fields:**
- `float[] _cooldownTimers = new float[3]` — remaining cooldown time
- `int[] _remainingCharges = new int[3]` — remaining charges (Advanced mode)
- `ShieldComponent _shieldComponent` — cached reference
- `bool _lastSnakeInRange = false` — for range change event debounce

**In Awake():**
- Cache: `_shieldComponent = GetComponent<ShieldComponent>();` (or GetComponentInParent if TuneController is on a child)
- Initialize charges: `if (!_isSimpleMode) _remainingCharges = (int[])_spellCharges.Clone();`

**In Update():**
After existing slider update, add:
1. **Cooldown tick**: `for (int i = 0; i < 3; i++) { if (_cooldownTimers[i] > 0f) { _cooldownTimers[i] -= Time.deltaTime; if (_cooldownTimers[i] <= 0f) { _cooldownTimers[i] = 0f; GameEvents.TuneCooldownExpired(i + 1); } } }`
2. **Range indicator update** (only when not casting): Check `HasSnakeInRange(_spellCastRange)` and compare to `_lastSnakeInRange`. If changed, fire `GameEvents.SnakeInRangeChanged(newValue)` and update `_lastSnakeInRange`.

**Modify OnTuneKeyPressed(int tuneNumber):**
After existing unlock guard (`if (!_tuneUnlocked[idx]) return;`), add these guards in order:

1. **Cooldown guard**: `if (_cooldownTimers[idx] > 0f) return;` — silently blocked
2. **Charge guard** (Advanced mode only): `if (!_isSimpleMode && _remainingCharges[idx] <= 0) return;` — no charges left
3. **Range guard for Move/Daze** (tunes 1 and 2): `if (tuneNumber <= 2 && !HasSnakeInRange(_spellCastRange)) return;` — no snake in range, block cast
4. **Shield active guard** (tune 3 only): `if (tuneNumber == 3 && _shieldComponent != null && _shieldComponent.IsShieldActive) return;` — cannot recast while active

**Modify EndTune() — Success case:**
After existing `GameEvents.TuneSuccess()` and `GameEvents.TuneSuccessWithId(tuneNumber)` calls:

1. **Start cooldown**: `_cooldownTimers[tuneNumber - 1] = _cooldownDurations[tuneNumber - 1]; GameEvents.TuneCooldownStarted(tuneNumber, _cooldownDurations[tuneNumber - 1]);`
2. **Consume charge** (Advanced mode): `if (!_isSimpleMode) _remainingCharges[tuneNumber - 1]--;`
3. **Shield activation** (tune 3 only): `if (tuneNumber == 3 && _shieldComponent != null) { _shieldComponent.ActivateShield(); }` — directly activate shield on Tune 3 success
4. **For Tune 3 (Shield): Do NOT fire `GameEvents.TuneSuccessWithId(3)`** — Shield has no snake effect. Replace the unconditional TuneSuccessWithId with a conditional: `if (tuneNumber <= 2) GameEvents.TuneSuccessWithId(tuneNumber);` — only Move/Daze fire the snake-targeting event.

**Add HasSnakeInRange method:**
```csharp
private bool HasSnakeInRange(float range)
{
    Collider[] hits = Physics.OverlapSphere(transform.position, range);
    foreach (var hit in hits)
    {
        if (hit.GetComponent<SnakeEnchanter.Snakes.SnakeAI>() != null)
            return true;
    }
    return false;
}
```
