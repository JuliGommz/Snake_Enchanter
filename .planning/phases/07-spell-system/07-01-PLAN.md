**SpellScrollPickup.cs** — New file in `Assets/_Project/Scripts/Level/` namespace `SnakeEnchanter.Level`:

MonoBehaviour that goes on each scroll prefab in the cave. Handles two collection methods and proximity glow.

SerializeFields:
- `int _tuneNumberToUnlock` (1, 2, or 3)
- `string _scrollName` (e.g., "Scroll of Movement")
- `string _scrollDescription` (e.g., "Hold [1] and release in the glowing zone to charm snakes away.")
- `float _glowMaxDistance = 8f`
- `float _glowMaxIntensity = 3f`

Requirements:
1. **Walk-over collection**: `OnTriggerEnter(Collider)` — check `other.CompareTag("Player")`, call `Collect()`.
2. **Click collection**: Use camera raycast approach (NOT OnMouseDown — cursor is locked in first-person). Add a public `Interact()` method that can be called from PlayerController's raycast. Also keep OnMouseDown as fallback.
3. **Proximity glow**: In `Update()`, calculate distance to player. Use `Shader.PropertyToID("_EmissionColor")` cached as static readonly. Apply emission color = `Color.yellow * (t * _glowMaxIntensity)` where `t = 1 - Clamp01(dist / _glowMaxDistance)`. Enable `_EMISSION` keyword on material.
4. **Collect()**: Set `_collected = true`, `gameObject.SetActive(false)`, fire `GameEvents.ScrollCollected(_tuneNumberToUnlock, _scrollName, _scrollDescription)`.
5. In `Awake()`, find player via `GameObject.FindWithTag("Player")` and cache `_playerTransform`. Get `_renderer = GetComponent<Renderer>()` or `GetComponentInChildren<Renderer>()`.
6. Guard all methods with `if (_collected) return;`.

Add standard project header comment (AI-ASSISTED, version v1.0).

**SpellUnlockSystem.cs** — New file in `Assets/_Project/Scripts/TuneSystem/` namespace `SnakeEnchanter.Tunes`:

MonoBehaviour that manages the unlock flow. Sits on a dedicated GameObject in the scene (or on the Player).

SerializeFields:
- `GameObject _scrollPanel` — the pause panel UI root (disabled by default)
- `UnityEngine.UI.Text _scrollNameLabel` or `TMPro.TextMeshProUGUI _scrollNameLabel` — use TMPro since project uses it
- `TMPro.TextMeshProUGUI _scrollDescriptionLabel`
- `TMPro.TextMeshProUGUI _scrollKeyLabel`

Behavior:
1. `OnEnable()`: subscribe to `GameEvents.OnScrollCollected += OnScrollCollected`.
2. `OnDisable()`: unsubscribe.
3. `OnScrollCollected(int tuneNumber, string name, string description)`:
   - Fire `GameEvents.TuneUnlocked(tuneNumber)` — other systems (HUD, TuneController) react
   - Show panel: set `_scrollPanel.SetActive(true)`, populate name/description/key labels
   - Key label text: `"Press [{tuneNumber}] to cast"`
   - Pause game: `Time.timeScale = 0f; GameEvents.GamePaused(true);`
   - Start coroutine `WaitForAnyKey()`
4. `WaitForAnyKey()` coroutine:
   - `yield return new WaitForSecondsRealtime(0.2f);` — buffer to prevent instant dismiss
   - `yield return new WaitUntil(() => UnityEngine.InputSystem.Keyboard.current.anyKey.wasPressedThisFrame);`
   - Hide panel: `_scrollPanel.SetActive(false)`
   - Resume: `Time.timeScale = 1f; GameEvents.GamePaused(false);`

CRITICAL: Use `WaitForSecondsRealtime` (NOT `WaitForSeconds`) because `Time.timeScale = 0`.

Add `using UnityEngine.InputSystem;` and `using TMPro;`.

Add standard project header comment (AI-ASSISTED, version v1.0).
