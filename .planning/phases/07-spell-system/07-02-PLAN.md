  <action>
Create `Assets/_Project/Scripts/UI/SpellHUDController.cs` in namespace `SnakeEnchanter.UI`.

This MonoBehaviour manages the dynamic HUD that starts empty and adds slots as scrolls are collected.

**SerializeFields:**
- `Transform _slotsContainer` — parent for slot GameObjects (HorizontalLayoutGroup recommended)
- `GameObject _slotPrefab` — prefab for one tune slot (will be created manually in Unity Editor later)
- `Color[] _tuneColors = { Color.green, Color.blue, new Color(1f, 0.85f, 0f) }` — green=Move, blue=Daze, gold=Shield
- `string[] _tuneNames = { "Move", "Daze", "Shield" }`
- `Sprite[] _keyIconSprites` — array of 3 key-shape sprites (one per tune slot). Per user decision #8: each slot shows a physical key shape with the number on it, not just a plain number. Assign these in Inspector (placeholder sprites created in Unity Editor).

**Private fields:**
- `GameObject[] _slots = new GameObject[3]` — instantiated slot references
- `CanvasGroup[] _slotCanvasGroups = new CanvasGroup[3]` — for fade-in reveal

**Event subscriptions:**
- `OnEnable()`: subscribe to `GameEvents.OnTuneUnlocked`
- `OnDisable()`: unsubscribe

**OnTuneUnlocked(int tuneNumber):**
1. `int idx = tuneNumber - 1;`
2. Guard: `if (idx < 0 || idx >= 3 || _slots[idx] != null) return;` — prevent duplicates
3. Instantiate `_slotPrefab` as child of `_slotsContainer`
4. Store in `_slots[idx]`
5. Configure the slot:
   - Find child "KeyIcon" (Image) and set `sprite = _keyIconSprites[idx]` — physical key shape per user decision #8
   - Find child "KeyLabel" (TMPro) and set text to `tuneNumber.ToString()` — number overlaid on the key icon
   - Find child "SpellName" (TMPro) and set text to `_tuneNames[idx]`
   - Find child "Background" (Image) and set color to `_tuneColors[idx]`
6. Add a `CanvasGroup` component if not present, set `alpha = 0`
7. Store in `_slotCanvasGroups[idx]`
8. Start coroutine `RevealSlot(idx)`

**RevealSlot(int idx)** coroutine:
- Lerp `_slotCanvasGroups[idx].alpha` from 0 to 1 over 0.5 seconds
- Use `Time.unscaledDeltaTime` because this might be called right after the pause panel dismiss (timeScale may still be transitioning)

**Slot prefab structure** (document as comment in code — will be built in Unity Editor):
```
SlotPrefab (RectTransform, CanvasGroup)
  ├── Background (Image — colored bg)
  ├── KeyIcon (Image — physical key shape sprite, per user decision #8)
  │   └── KeyLabel (TextMeshProUGUI — "1", "2", "3" — child of KeyIcon, overlaid on key shape)
  └── SpellName (TextMeshProUGUI — "Move", "Daze", "Shield")
```

**Additional consideration:** The HUD slot layout should work with a HorizontalLayoutGroup on `_slotsContainer` for automatic positioning. Add a comment noting this.
