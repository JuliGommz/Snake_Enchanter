<objective>
Complete the submission folder structure by creating Arbeitsdateien/GME_Julian_Gomez/, Anwendung/, and Trailer/ at the repo root.

**The Unity Assets problem — and its solution:**
The submission spec requires `Arbeitsdateien/GME_Julian_Gomez/[Gesamtes Assets/ Verzeichnis]`. However, Unity requires `Assets/` to be at the project root — moving it would break the entire project.

The solution: Create `Arbeitsdateien/GME_Julian_Gomez/ASSETS_AT_ROOT.md` — a short note that tells the evaluator where the Unity Assets are. The Unity project files (Assets/, ProjectSettings/, Packages/) remain at the repo root, which IS the "Arbeitsdateien" conceptually.

**Anwendung/:** The built .exe cannot be in git (100MB+ binary, gitignored). Create the folder with ReadMe.txt. The evaluator copies the build files here manually or runs a fresh build. A `.gitignore` inside Anwendung/ will ignore the large binaries but track the ReadMe.

**Trailer/:** Empty placeholder. The MP4 will be added last.
</objective>
